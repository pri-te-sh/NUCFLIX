X-Ray · TV & phone

Press X-Ray in the player and NUCFLIX pauses to show who's in the scene, who they play, a little trivia and the full cast. Pick anyone for their bio and other titles.

People are found by face matching against the title's cast photos from TMDB, not by asking an AI who they are. On labelled frames from Charade (1963), the vision models named the film's stars instead (5–6 of 16 right), while face matching got all 16. When it can't recognise anyone, it simply shows the full cast.

Under the hood

Engineered for messy real-world streams.

IPTV providers cut corners. NUCFLIX quietly works around them so the picture starts, the sound plays and your line is never double-booked.

One stream at a time, respected

Downloads pause the moment anyone in the household starts watching, then resume exactly where they stopped.

Watched episodes clean themselves up

A downloaded episode is removed once it's been watched on any device, freeing space automatically.

Audio the Fire TV can't decode

DTS and Dolby TrueHD tracks fall back to a bundled FFmpeg decoder instead of playing silently.

Repairs broken files and feeds

Rebuilds missing H.264 headers in MKVs and re-bases live TS feeds whose audio drifts hours from the video.

Resilient on flaky lines

Smart retries for busy single-connection lines, stall recovery for live TV and resumable, piece-by-piece downloads.

Fast on modest hardware

A locally cached catalog, pre-rendered rows and an R8-shrunk build keep a Fire TV stick responsive with tens of thousands of titles.

How it works

Firebase in the middle. Your provider stays yours.

The apps sync through Firestore and call Cloud Functions for AI. Video always streams straight from your IPTV provider to the device.

Get smarter

Privacy & security

Private by design.

Your provider login and your household's data are locked down at every layer.

Logins never touch the disk

IPTV credentials live in your account and only in memory on devices. Downloads store placeholders, not passwords.

Locked-down rules, tested

Firestore rules let only you and your paired TVs into the household, and TVs can't change lines or profiles. Emulator tests cover every rule.

AI that sees only what it needs

Small frames, category names and search text. Never your login, profiles or history, and frames are never stored. X-Ray compares a frame's faces with the title's cast photos and keeps only who was found.

Get started

Up and running in four steps.

You'll need a Firebase project with Authentication and Firestore. The AI features additionally need the Blaze plan and an Ollama API key; without them everything else still works.

firebase/
$ cd firebase && npm install
$ npm test               # security-rules tests on the local emulators
$ npm run deploy:rules   # deploy once they pass
firebase/
$ cd functions && npm install && cd ..
$ npx firebase functions:secrets:set OLLAMA_API_KEY   # stored in Secret Manager
$ npm run test:functions                               # fake AI, no key needed
$ npm run deploy:functions

Each household gets 4,000 AI calls a day. Normal viewing uses a few dozen.

repository root
$ ./scripts/fetch-vlckit.sh   # downloads MobileVLCKit, kept out of git
$ open NucFlix.xcodeproj      # pick your team, run on your iPhone

Changing the bundle ID? Register it in Firebase and replace GoogleService-Info.plist.

NucFlixFireTV/
$ ./build.sh                    # aapt2 → javac → R8 → zipalign → apksigner
$ ./build.sh --install          # build, install and launch on your Fire TV
$ ./build.sh --debug --install  # debuggable WebView for chrome://inspect

No Gradle needed. Back up keystore.jks and local.properties together.
